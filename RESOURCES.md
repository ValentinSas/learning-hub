# Resources

Each track has one **main path** (the thing you follow week by week). Everything else is for when something doesn't click or you need to look something up.

## Python

| Resource | Use it for |
|---|---|
| **[Python Tutorial](https://docs.python.org/3/tutorial/)**, main path | Phases 1 and 3, chapter by chapter |
| [Python Standard Library reference](https://docs.python.org/3/library/) | Looking up modules (`pathlib`, `json`, `argparse`, `re`, …) |
| [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/) (free online) | A second, more practical explanation of the same basics |
| [Real Python](https://realpython.com/) | Focused articles when one topic won't click |
| [Exercism · Python track](https://exercism.org/tracks/python) | Short exercises with feedback |
| [venv docs](https://docs.python.org/3/library/venv.html) | Virtual environments |
| [pytest](https://docs.pytest.org/) | Testing (Week 16) |
| [Ruff](https://docs.astral.sh/ruff/) | Linting + formatting (Week 15) |
| [PyYAML](https://pyyaml.org/wiki/PyYAMLDocumentation) | YAML parsing (Week 17) |
| [FastAPI](https://fastapi.tiangolo.com/) | The hub dashboard (Weeks 17–19) |
| [Jinja2](https://jinja.palletsprojects.com/) | HTML templates (Week 18) |

## C++

| Resource | Use it for |
|---|---|
| **[learncpp.com](https://www.learncpp.com/)**, main path | Phase 2, chapter by chapter |
| [cppreference](https://en.cppreference.com/) | The reference: look up any function or container |
| [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines) | How to write modern C++ well (skim, don't read it all) |
| [Compiler Explorer](https://godbolt.org/) | Try small snippets in the browser, see what the compiler does |
| [Exercism · C++ track](https://exercism.org/tracks/cpp) | Short exercises with feedback |
| [CMake tutorial](https://cmake.org/cmake/help/latest/guide/tutorial/index.html) | Build system (Week 10 onward) |
| [GDB documentation](https://sourceware.org/gdb/documentation/) | Debugger reference (Week 11) |

## Linux

| Resource | Use it for |
|---|---|
| **[The Linux Command Line](https://linuxcommand.org/tlcl.php)** (William Shotts, free PDF), main path | Shell, permissions, processes, scripting |
| [The Missing Semester of Your CS Education](https://missing.csail.mit.edu/) (MIT, 2026 edition) | Shell, command-line environment, debugging, git, with videos |
| [OverTheWire · Bandit](https://overthewire.org/wargames/bandit/) | Shell practice as a game, over ssh |
| [explainshell](https://explainshell.com/) | Paste a command, see what each part does |
| [Linux man pages online](https://man7.org/linux/man-pages/) | Same as `man`, but searchable in the browser |
| [GNU Bash manual](https://www.gnu.org/software/bash/manual/) | Bash scripting reference |
| [systemd man pages](https://www.freedesktop.org/software/systemd/man/latest/) | Unit files, `systemctl`, timers (Weeks 14, 17) |
| [ArchWiki](https://wiki.archlinux.org/) | Excellent explanations, useful on any distro |
| [WSL docs](https://learn.microsoft.com/en-us/windows/wsl/) | Your setup: file access between Windows and Linux, WSLg, networking |
