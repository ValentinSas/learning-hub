# Practice

Exercises and small scripts, one folder per track:

- `python/`: tutorial exercises, `hello.py`, `new_week.py`, `hours.py`
  - `python/refresh/`: the Python files you already had before the hub
- `cpp/`: learncpp exercises (one subfolder per chapter works well, e.g. `cpp/ch12-pointers/`)
  - `cpp/refresh/`: the C++ files you already had before the hub
- `bash/`: shell scripts
  - `check_env.sh`: checks your setup (tools, git, SSH to GitHub). Run with `bash practice/bash/check_env.sh`
  - `backup.sh`: you write this one in Week 7

It doesn't need to be pretty. It needs to be committed.
